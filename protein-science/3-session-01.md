## 2. Environment / tooling issues resolved

- **Bash brace expansion (`{a,b,c}`)**: fails if spaces are added after the commas
  (`{a, b, c}`) — bash then treats the whole `{...}` as literal text instead of
  expanding it, which produced stray folders named literally `{predictions` and
  `notes}` in the home directory. Fix: no spaces inside braces, or just create
  directories individually with separate `mkdir -p` calls (safer/more portable
  across shells regardless).
- **PyMOL picking clutter** (`<sele>`, `pk1`, `pk2`, `pkmol`, etc.): these are
  auto-generated by clicking atoms in the viewer, not something typed. Harmless,
  cleared with `delete pk*` and `delete sele`. `get_names` lists everything
  currently in the session if you need to check what's safe to remove.

## 3. Structure prediction (ColabFold)

- Notebook: [ColabFold (AlphaFold2-based)](https://colab.research.google.com/github/sokrypton/ColabFold/blob/main/AlphaFold2.ipynb)
- `jobname`: `lysozyme-hewl-colabfold-run1`
- `num_relax`: 0 (no Amber relaxation for this first pass)
- Output: 5 ranked models (`rank_1`–`rank_5`), each `unrelaxed`, plus pLDDT and
  PAE diagnostic plots and an MSA sequence-coverage plot.

### Sequence coverage (MSA depth)
Deep coverage (thousands of homologous sequences) across nearly the full 129
residues, only tapering near the N-/C-termini — as expected for one of the
most heavily sequenced proteins in the databases. Deep MSA coverage is a
leading indicator of high prediction confidence, since it gives the model more
evolutionary co-variation signal per position.

### pLDDT (per-residue confidence, 0–100)
- All 5 ranked models tracked closely together, mostly in the **93–99** range.
- Minor dips (~93) near positions ~47 and ~68 — likely turns/loops.
- Deepest dip: **~86–90 at position ~101**, consistent across all 5
  independently generated models.
- Structural check in PyMOL confirmed residue ~101 sits in **a loop connecting
  two alpha helices** — exactly the kind of region expected to show reduced
  confidence, since loops lack the regular H-bonding network that locks down
  helices, and are genuinely more conformationally flexible.

### PAE (Predicted Aligned Error)
Near-uniform low error (dark blue) across the entire 129×129 matrix for all
5 ranks — the "one solid block" pattern expected for a single compact rigid
domain with no independently-moving parts. A faint lighter band near
position ~100–105 lines up with the pLDDT dip at the same position — a good
example of the two metrics cross-confirming each other.

## 4. PyMOL workflow

```bash
conda activate pymol-env
cd ~/protein-design-practice/predictions/lysozyme-hewl-run1
pymol lysozymehewlcolabfoldrun1_ce6c6_unrelaxed_rank_001_alphafold2_ptm_model_5_seed_000.pdb
```

Key PyMOL commands used:

```
# Color by pLDDT (stored in the B-factor column by AlphaFold/ColabFold)
spectrum b, red_yellow_blue, minimum=50, maximum=100

# Basic cartoon representation
hide everything
show cartoon

# Inspect the residue ~101 confidence dip directly
select dip_region, resi 98-104
show sticks, dip_region
color magenta, dip_region
zoom dip_region, 5

# View reset options
orient              # reframe camera without touching colors/selections
reinitialize        # full session reset
zoom                # reframe on everything loaded

# Clean up click-picking clutter
delete pk*
delete sele
get_names            # list everything currently loaded/selected
```

**Reference:** [PyMOL `spectrum` command](https://pymolwiki.org/index.php/Spectrum)

## 5. Validation against the experimental structure

Fetched the real crystal structure directly from RCSB and superimposed the
prediction onto it:

```
fetch 1dpx, type=pdb

# align does sequence alignment first, then iteratively refines the
# structural superposition, dropping outlier atoms — right choice here
# since predicted and experimental are the exact same sequence
align lysozymehewlcolabfoldrun1_ce6c6_unrelaxed_rank_001_alphafold2_ptm_model_5_seed_000, 1dpx

hide everything
show cartoon
color skyblue, lysozymehewlcolabfoldrun1_ce6c6_unrelaxed_rank_001_alphafold2_ptm_model_5_seed_000
color orange, 1dpx
hide everything, 1dpx and hetatm   # hide the two crystallographic chloride ions
orient
```

**Reference:** [PyMOL `align` command](https://pymolwiki.org/index.php/Align) ·
[PyMOL `super` command](https://pymolwiki.org/index.php/Super) (sequence-independent alternative)

### Result

**RMSD = 0.355 Å** after refinement — essentially at the noise floor between
two independently solved crystal structures of the same protein. This is a
strong, ground-truth confirmation that the pLDDT/PAE self-reported confidence
metrics were accurate, not just internally consistent.

## 6. Takeaways

- Full pipeline verified end-to-end: FASTA → ColabFold prediction → pLDDT/PAE
  interpretation → PyMOL loading/coloring → structural inspection →
  experimental validation.
- Established a **calibrated reference point**: what "high confidence, correct
  prediction" looks like across all three metrics (pLDDT, PAE, RMSD)
  simultaneously, on a case where the answer is already known. Useful for
  judging less-certain results later, when no crystal structure exists to
  check against.
- Confirmed the pLDDT dip at residue ~101 was genuine biological signal (a
  flexible interhelical loop), not a modeling artifact — a good first example
  of correctly interpreting a confidence dip rather than dismissing it.
